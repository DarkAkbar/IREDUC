# Photos de démonstration IREDUC

Sources locales utilisées par `npm run seed:demo` (copiées vers `uploads/demo/`).

```
maison/          → biens type Maison
appartement/     → Appartement
villa/           → Villa
terrain/         → Terrain
services/<slug>/ → prestataires par catégorie
providers/       → logos partenaires
```

Régénérer les placeholders : `node scripts/generate-seed-assets.mjs`
