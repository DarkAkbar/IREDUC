# IREDUC Admin

Panneau d'administration web (React + Vite + TypeScript).

## Prérequis

- API IREDUC démarrée (`cd api && npm run dev`)
- Comptes seed : `admin@ireduc.cd` / `Admin123!` ou `superadmin@ireduc.cd` / `SuperAdmin123!`

## Configuration

```bash
cp .env.example .env
```

Variable : `VITE_API_URL` (ex. `http://localhost:3000/api/v1`)

## Lancement

```bash
npm install
npm run dev
```

L'interface est disponible sur [http://localhost:5174](http://localhost:5174).
